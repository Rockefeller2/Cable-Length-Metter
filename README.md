# Cable-Length-Metter
# Измеритель длинный кабеля на Arduino Nano
# ! [Внешний вид и размеры устройства]
! 1000005253.jpg 1000005254.jpg 1000005255.jpg

## 🛠️ Используемые компоненты
* **Микроконтроллер:** Arduino Nano (ATmega328P, Old Bootloader)
* **Дисплей:** OPEN-SMART 3.2" TFT LCD Shield (Драйвер ILI9329)
* **Энкодер:** ЛИР-МИ-158АТ (1024 импульса/оборот, TTL 5V)
* **Кнопка:** Тактовая, нормально открытая (сброс показаний)
* **Питание:** Внешний блок питания 5В 2А
* **Механика:** Измерительное колесо 150 мм, прижимной ролик с регулировкой.

## 🔌 Схема подключения (Распиновка)
| Полная распиновка находиться в файле table_20261027.csv |
| Компонент | Пин на Arduino Nano | Примечание |
| :--- | :--- | :--- |
| **Энкодер (Канал A)** | D10 | Зеленый провод |
| **Энкодер (Канал B)** | D11 | Красный провод |
| **Энкодер (+5V)** | 5V | Коричневый провод |
| **Энкодер (GND)** | GND | Белый провод + оплетка |
| **Кнопка сброса** | D12 | Второй контакт на GND, используется INPUT_PULLUP |
| **Экран** | Стандартный шилд | D8-D7, A0-A4 (см. код) |
| **Питание** | 5V, GND | Общая земля для всех элементов |

## 📚 Необходимые библиотеки
Для компиляции скетча установите следующие библиотеки:
* `MCUFRIEND_kbv` (для TFT экрана)
* `Adafruit_GFX` (и её зависимость `Adafruit_BusIO`)
* `PinChangeInterrupt` (для прерываний на пинах D10/D11)

## ⚙️ Калибровка
В коде используется переменная `PULSES_PER_METER` (по умолчанию `4346.0`).
Для точной настройки:
1. Возьмите эталонный кусок кабеля (например, ровно 10 метров).
2. Прокатайте его через устройство.
3. Если прибор показал, например, 9.85 м, скорректируйте коэффициент в коде по формуле: 
   `Новый коэффициент = 4346.0 * (10 / 9.85)`
4. Загрузите обновленный скетч.
